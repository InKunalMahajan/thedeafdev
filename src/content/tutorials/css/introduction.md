# CSS Introduction

CSS means **Cascading Style Sheets**.

CSS is used to design and style HTML pages.

## Example

```css
h1 {
  color: blue;
  font-size: 40px;
}
```

## Simple Explanation

CSS can change color, size, spacing, layout, and responsive design.
